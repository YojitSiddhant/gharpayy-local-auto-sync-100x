# Phase 1 foundation

This repository contains the initial Next.js, FastAPI, SQLAlchemy, and Alembic foundation. OCR, ML, screenshot capture, review, CRM integration, and business-domain tables are intentionally out of scope.

The visual direction is informed by the read-only `lead-loved-flow` reference. Python dependency research was informed by the read-only `Gharpayy_Local_Sync_FINAL` reference; no source code, data, models, or credentials were copied.
